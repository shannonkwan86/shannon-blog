# 内容编写约定

## 文章分类

每篇文章使用一个分类。分类用于表达文章主题或内容形态，当前项目使用：

- `XCPC`：竞赛题解与训练复盘。
- `CSAPP`：CSAPP 课程、实验与相关学习记录。
- `NJU-生成式软件工程`：南京大学生成式软件工程课程与相关学习记录。
- `随笔`：旅行、生活和其他非技术记录。

如果文章不属于现有分类，应先根据文章内容提出分类名称，并同步更新本文档与站点分类说明。

## 标签

标签用于检索具体技术主题，而不是重复文章分类。

- 每篇文章建议使用 0–3 个标签。
- 使用具体主题，例如 `图论`、`动态规划`、`C++`、`Astro`。
- 不使用 `XCPC`、`CSAPP`、`NJU-生成式软件工程`、`随笔` 等与分类重复的标签。
- 避免“学习”“记录”等泛化标签。
