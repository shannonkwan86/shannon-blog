## M. Find the Easiest Problem

**题意：** 给定一次 ICPC 赛制比赛的所有提交记录。若一支队伍曾经通过某题，就计入这道题的通过队伍数。求通过队伍数最多的题目；若有多题并列，输出题目 ID 字典序最小的一题。

**思路：**

对每道题维护一个集合，读入一条提交记录时，只有结果为 `accepted` 才将队伍名加入对应集合。集合会自动去重，因此集合大小恰好等于通过该题的不同队伍数。

最后枚举所有出现过的题目，选择集合大小最大的题目；若通过队伍数相同，则选择题目 ID 更小的一题。题目 ID 仅为 `A` 到 `Z`，也可以直接开 $26$ 个集合。

**实现：** 使用 `set<string>` 数组存储每道题的通过队伍。维护当前答案时，先比较集合大小，再比较题目 ID 即可。

**复杂度：** 设共有 $n$ 条提交记录。每次插入集合的复杂度为 $O(\log n)$，总时间复杂度为 $O(n\log n)$，额外空间复杂度为 $O(n)$。

## A. World Cup

**题意：** $32$ 支队伍的实力互不相同，中国队编号为 $1$。可以任意安排小组赛分组，比赛中实力更强的一方必胜。求中国队能够取得的最好名次：冠军、亚军、四强、八强、十六强或小组未出线，分别输出 $1,2,4,8,16,32$。

**思路：**

将所有实力排序，记中国队从强到弱的名次为 $pos$，即实力严格大于中国队的队伍数加一。只需根据 $pos$ 判断答案。

可以按“希望最终在哪一轮输掉”倒推。中国队要在某轮输，前面的轮次必须都赢下来；据此安排小组赛和淘汰赛路径中需要比中国队弱的队伍，并数出中国队最多能排到第几名。

1. **夺冠：** 只有实力第一才能击败所有对手，因此 $pos=1$。
2. **决赛失利：** 必须先进入决赛，因此中国队要是自己半区最强。比它强的队伍可以都放在另一半区，作为另外半区各条路径的胜者，最后由其中的冠军淘汰中国队。另一半区至多容纳这 $4$ 支更强队伍，故中国队至多排在第 $5$ 名，即 $pos\le5$。
3. **半决赛失利：** 要先赢下四分之一决赛。一个队伍能走到四分之一决赛，需要有 $6$ 支比它弱的队伍为其安排出路径；中国队和四分之一决赛的对手各需要这样一组 $6$ 支队伍。中国队再战胜该对手时，对手本身也比中国队弱；而对手路径中的 $6$ 支队伍当然也比中国队弱。两组路径不重叠，因此共有 $6+6+1=13$ 支队伍比中国队弱，得到 $pos\le32-13=19$。
4. **四分之一决赛失利：** 中国队需要先赢下十六强赛。可以让它以小组第二出线，再战胜一个小组第一；对应地需要有 $6$ 支比它弱的队伍，故 $pos\le26$。
5. **十六强失利：** 只要能从小组前二出线即可。小组赛中一共 $6$ 个胜场分给四支队伍，前二至少各需两胜；中国队只要比两支同组队伍强，就能取得两胜，因此 $pos\le30$。
6. **小组未出线：** $pos\ge31$ 时，最多只有一支队伍比中国队弱，无法在小组赛拿到前二，答案为 $32$。

综上，直接按阈值 $1,5,19,26,30$ 分类即可。

**实现：** 读入实力后排序，用 `upper_bound` 求出中国队前面有多少支更强队伍，从而得到 $pos$。随后使用 if-else 输出对应结果。

**复杂度：** 每组数据排序的时间复杂度为 $O(32\log 32)$，额外空间复杂度为 $O(32)$。

## F. Make Max

**题意：** 给定一个正整数序列。一次操作可以选择一个不全相等的连续子数组，将其中所有数变成该子数组的最大值。求最多能进行多少次操作。

**思路：**

将相邻且相等的元素看成一个连续段。设当前最小段的值为 $x$，长度为 $len$，左右相邻段的值为 $L,R$；不存在的一侧视为无穷大。令：

$$
y=\min(L,R)
$$

将该段提升为 $y$ 可以贡献恰好 $len$ 次操作：从靠近值为 $y$ 的一端开始，每次选择一个值为 $x$ 的元素和相邻的一个值为 $y$ 的元素，就能只把这个元素改为 $y$。逐个扩张直到整个段都变成 $y$，共进行 $len$ 次。

若直接把这段提升到大于 $y$ 的值，就会跳过从 $x$ 到 $y$ 的这些操作机会，无法得到更优答案。因此每次只提升到两侧较小值是最优的。提升后与同值相邻段合并，继续处理当前所有段中值最小的一段，直到整个序列只剩一个段。

**实现：**

初始时每个位置单独作为一个段，维护：

- `num[i]`：以 `i` 为代表的段长度；
- `f[i][0]`、`f[i][1]`：该段左右相邻段的代表位置，组成双向链表；
- `ok[i]`：该段是否已在合并中失效。

优先队列存储 `(段值, 段代表)`，每次取出值最小的有效段。将段值改为左右较小值时，答案加上 `num[i]`；然后合并所有同值相邻段并更新双向链表。

优先队列中会保留段合并前的旧记录，弹出时通过 `ok` 跳过即可。设 `v` 为当前存活段数：与一侧合并时 `v` 减一，左右两侧同时合并时 `v` 减二；当 `v=1` 时结束。

**复杂度：** 每次合并都会减少至少一个连续段，总共至多进行 $O(n)$ 次有效处理。每次优先队列操作的复杂度为 $O(\log n)$，总时间复杂度为 $O(n\log n)$，额外空间复杂度为 $O(n)$。

## C. Permutation Counting 4

**题意：** 给定 $n$ 个区间 $[l_i,r_i]$，统计满足 $l_i\le p_i\le r_i$ 的排列 $p$ 的数量，对 $2$ 取模。

**思路：**

把第 $i$ 个区间写成矩阵 $A$ 的一行：区间内的位置为 $1$，其余位置为 $0$。合法排列数就是 $A$ 的 permanent。模 $2$ 下，行列式中每一项的正负号没有区别，因此：

$$
\operatorname{per}(A)\equiv\det(A)\pmod 2
$$

于是只需判断 $\det(A)$ 是 $0$ 还是 $1$。

对同一左端点的区间做行消元。若当前有：

```text
[i, r1]  [i, r2]  [i, r3]      (r1 < r2 < r3)
```

保留最短的第一条作为第 $i$ 列的主元。其余行从后往前依次与前一行相加；模 $2$ 下相加会消掉两条区间共同的前缀，连续区间的结构保证剩余部分仍然是一个区间：

```text
[i, r2] - [i, r1] = [r1 + 1, r2]
[i, r3] - [i, r2] = [r2 + 1, r3]
```

对所有区间依次消元后，这组区间等价于：

```text
[i, r1]  [r1 + 1, r2]  [r2 + 1, r3]
```

这里的“等价”指行列式不变，因为每一步都是“用一行加到另一行”的初等行变换。新产生的区间左端点严格大于 $i$，可以留给后面继续处理。

从左到右扫左端点。处理到 $i$ 时，将所有左端点为 $i$ 的右端点排序：最小右端点对应一条主元行；相邻两个右端点 $r_j,r_{j+1}$ 则产生新区间 $[r_j+1,r_{j+1}]$。代码把这一步批量完成，而不需要真的保存矩阵。

**正确性证明：**

每次用一行加到另一行、消掉共同前缀，都是初等行变换，始终保持原矩阵行列式不变。

- 若同一组中出现相同右端点，则有两条完全相同的行。两行相减得到零行，行列式为 $0$。
- 若处理到 $i$ 时没有左端点为 $i$ 的区间，前面至多已有 $i-1$ 个主元；剩余区间的左端点都大于 $i$，它们在前 $i$ 列均为 $0$，至多贡献 $n-i$ 的秩。总秩至多为：

  $$
  (i-1)+(n-i)=n-1
  $$

  因此矩阵不满秩，行列式为 $0$。
- 若每个 $i$ 都存在区间，且每组没有重复右端点，则每次都能留下一个左端点恰为 $i$ 的主元行。将这些主元行按 $i=1,2,\ldots,n$ 排列，得到一个上三角矩阵，且对角线全为 $1$，故行列式为 $1$。

因此，算法输出 `0` 当且仅当原矩阵行列式为 $0$；否则输出 `1`。再由 permanent 与 determinant 在模 $2$ 下相等，输出即为合法排列数模 $2$ 的结果。

**实现：** `vec[l]` 存储当前左端点为 `l` 的所有右端点。排序后，若相邻右端点相同立即输出 `0`；对于相邻右端点 `r1,r2`，向 `vec[r1+1]` 加入 `r2`，即生成区间 $[r1+1,r2]$。若某个 `vec[i]` 为空则输出 `0`，全部处理成功后输出 `1`。

**复杂度：** 处理过程中每次只对同一左端点的一组右端点排序并生成新区间，总时间复杂度为 $O(n\log n)$，额外空间复杂度为 $O(n)$。

**其他做法：**

- 也可以直接从排列的交换配对出发：若两个位置最终取到的值都落在其区间交集中，交换两个值后仍合法，因此这类方案成对出现，对模 $2$ 的答案没有贡献。递归地删去这种可配对的公共前缀，并用启发式合并维护区间集合，可以得到 $O(n\log^2 n)$ 的做法。
- 另一种更短的实现是把区间 $[l,r]$ 连成边 $(l,r+1)$，用并查集判断这些边是否成环；有环时答案为 `0`，无环时答案为 `1`。这是另一种图论视角。
